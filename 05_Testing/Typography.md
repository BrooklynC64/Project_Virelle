# Virelle Typography System

## Purpose

This document defines the typography style used across all Virelle branding.

Typography should communicate:

- Luxury
- Confidence
- Refinement
- Modern beauty science

---

# Typography Philosophy

Virelle combines two worlds:

## Timeless Luxury

Inspired by:

- Fine fragrance houses
- Fashion brands
- Premium skincare

Characteristics:

- Elegant
- Sophisticated
- Emotional

---

## Modern Beauty Science

Inspired by:

- Clinical skincare
- Innovation
- Clean design

Characteristics:

- Precise
- Minimal
- Trustworthy

---

# Primary Typeface

## Style

Elegant Serif

## Purpose

Used for:

- Logo
- Product names
- Major headlines
- Brand statements

## Personality

Communicates:

- Luxury
- Heritage
- Sophistication

---

# Recommended Font Direction

Examples:

- Cormorant Garamond
- Playfair Display
- Libre Baskerville
- Didot-inspired styles

---

# Secondary Typeface

## Style

Clean Sans Serif

## Purpose

Used for:

- Product descriptions
- Website copy
- Ingredient information
- Instructions

## Personality

Communicates:

- Modern
- Clean
- Professional

---

# Recommended Font Direction

Examples:

- Helvetica Neue
- Inter
- Avenir-style fonts
- Montserrat

---

# Logo Typography

The Virelle logo should feel:

- Minimal
- Balanced
- Elegant

Recommended characteristics:

✓ Wide spacing between letters

✓ Thin to medium weight

✓ Clean silhouette

✓ Timeless appearance

---

# Product Label Typography

Example:

VIRELLE

Signature Body Oil

LumiVeil™ Complex

100 mL / 3.4 fl oz

The hierarchy should be:

1. Brand name
2. Product name
3. Product benefit
4. Size information

---

# Typography Rules

## Do:

✓ Use generous spacing

✓ Keep layouts clean

✓ Allow empty space

✓ Prioritize readability

---

## Avoid:

❌ Overly decorative fonts

❌ Too many font styles

❌ Crowded layouts

❌ Trend-based typography

---

# Brand Feeling

Virelle typography should feel like:

A luxury perfume bottle sitting beside a modern skincare product.

Elegant enough for a vanity.

Clean enough for a laboratory.

---

# Final Typography Goal

When someone sees Virelle text, they should immediately think:

"Premium."

"Elegant."

"Well-designed."
