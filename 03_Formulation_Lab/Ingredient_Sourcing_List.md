# Virelle Ingredient Sourcing List

## Purpose

This document tracks all ingredients needed for Virelle prototype development.

The goal is to source high-quality cosmetic ingredients that support the Virelle product philosophy:

- Luxury skin feel
- Fast absorption
- Healthy skin benefits
- Elegant glow
- Premium sensory experience

---

## INCI Name

## Purpose

## Function

★★★★★

# Development Note

The first goal is not to create the final product.

The first goal is to understand:

- How each ingredient changes texture
- How quickly the formula absorbs
- How much glow is created
- How the skin feels after several hours

Each test will guide future formula revisions.
