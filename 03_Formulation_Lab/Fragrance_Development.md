# Virelle Fragrance Development

## Product

Virelle Signature Body Oil

---

# Purpose

This document defines the fragrance strategy for Virelle products.

The goal is to create scents that feel:

- Luxurious
- Sophisticated
- Memorable
- Skin-friendly
- Compatible with personal fragrance

---

# Virelle Fragrance Philosophy

Virelle fragrances should not smell like typical body care products.

Avoid:

- Artificial sweetness
- Overly strong synthetic scents
- Temporary trends

Focus on:

✓ Fine fragrance inspiration

✓ Elegant scent layering

✓ Emotional connection

✓ Long-lasting experience

---

# Signature Scent Identity

## Brand Feeling

The Virelle scent experience should communicate:

- Confidence
- Soft luxury
- Clean elegance
- Warm sophistication

"I smell expensive."

# Fragrance Performance Goals

The fragrance should:

✓ Be noticeable during application

✓ Feel sophisticated after absorption

✓ Last several hours

✓ Layer well with perfume

✓ Not overpower the skincare experience
